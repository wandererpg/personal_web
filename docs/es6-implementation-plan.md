# ES6 模块重构

## 目标与边界

所有新代码、测试和文档位于 `es6/`，不修改旧版本。保留界面、URL、身份验证、草稿、发布、课程表、留言板与音乐行为；不引入框架或新的动画依赖。

原生 ES Modules 用于浏览器和 Node.js：浏览器由 `public.js` 显式启动各功能，后台页面导入各自依赖，后端使用具名导出。共享模型不自动操作 DOM，也不写入全局命名空间。

`repoDir` 继续指向原 Git 仓库，文章、图片和音乐仍在原位置；`webDir` 指向新版本的页面。私人数据仍使用仓库外的 `BLOG_DATA_DIR`。不得复制、重置或公开私人数据。

## 验收

旧版 `npm test` 必须通过；新版 `npm --prefix es6 test` 与 `npm --prefix es6 run check` 必须通过。模块路由不得暴露服务器源码、测试、配置或私人目录。测试只使用临时数据和模拟 Git 发布，不推送远程、不修改现有课程或博客。
