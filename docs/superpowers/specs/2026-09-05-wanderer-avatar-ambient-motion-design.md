# Wanderer 头像卡片与动态星空设计

日期：2026-09-05  
状态：视觉方案已确认

## 1. 目标

更新首页右侧个人卡片，使其更明确地代表 Wanderer，同时让卡片与全站深空背景处于同一视觉空间。动效保持缓慢、低干扰，并延续现有液态玻璃交互。

## 2. 已确认方案

- 页面背景采用 **A：星尘漂移**，应用于 `index.html`、`projects.html` 和 `notes.html`。
- 首页个人卡片采用 **B：星云呼吸**。
- 卡片标题由“把好奇心，变成可见的东西。”改为小写 `wanderer`。
- 原星球位置改为圆形头像占位符，默认显示字母 `W` 和 `AVATAR` 标识。
- 卡片底色控制在约 45%–50% 不透明度，让星尘透过磨砂层，同时保证文字对比度。
- 卡片边框和外阴影弱化，避免与背景形成明显割裂。

## 3. 视觉与动效

### 全站背景

- 使用两层不同尺寸和亮度的星点。
- 近景层约 18 秒完成一次缓慢漂移，远景层约 30 秒反向漂移，形成轻微空间深度。
- 星点层使用放大的固定伪元素，通过 `translate3d` 移动，避免出现边缘空白。
- 原有深空渐变和网格保留，网格不参与移动。

### 个人卡片

- 卡片采用半透明深蓝渐变、约 15–20px 背景模糊和轻微饱和度增强。
- 青色与紫色模糊光团分别以约 8 秒和 10 秒缓慢移动、缩放和呼吸。
- 星云仅在个人卡片内部显示，不覆盖文字和交互控件。
- 保留现有液态玻璃高光、指针倾斜、按压反馈和桌面端垂直居中修复。

### 头像占位符

- 使用圆形玻璃容器、细描边和虚线外环。
- 占位状态显示 `W`；后续提供真实头像时，只需将内部内容替换为 `<img>`，无需改变卡片布局。
- 使用 `role="img"` 和明确的中文无障碍名称描述占位状态。

## 4. 实现边界

- HTML 仅调整首页 `.station-panel` 内部结构；项目和知识页面不新增个人卡片。
- CSS 扩展现有背景伪元素，并为头像、星云和星尘增加独立样式与关键帧。
- 不新增 JavaScript；环境动效由 CSS 完成，现有 `liquid-glass.js` 保持原职责。
- 不包含头像上传、裁剪、浏览器存储、动效开关或 WebGL/Canvas 粒子系统。

## 5. 响应式、可访问性与性能

- 移动端缩小头像和卡片间距，保持现有单列布局，不产生横向滚动。
- 动效只改变 `transform` 和 `opacity`，不持续修改布局属性。
- 动画层设置 `pointer-events: none`，不遮挡导航、链接或播放器。
- `prefers-reduced-motion: reduce` 下停止星尘、星云和头像呼吸，保留静态星空与玻璃材质。
- CSS 或动画不可用时，`wanderer`、头像占位符和原有说明文字仍正常显示。

## 6. 测试与验收

- 自动化测试确认新设计文档、`wanderer` 标题、头像占位符、星尘与星云样式钩子存在。
- 自动化测试确认旧标题和旧星球元素不再出现在个人卡片中。
- 自动化测试确认所有新增循环动画均受 `prefers-reduced-motion` 控制。
- 浏览器验证桌面端与移动端布局、卡片透明度、背景连续性、无横向溢出和无控制台错误。
- 触碰个人卡片时不得再次出现垂直居中丢失或向下跳动。
