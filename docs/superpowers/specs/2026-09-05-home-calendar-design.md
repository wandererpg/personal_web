# 首页日历 MVP 设计文档

> 状态：已确认
> 日期：2026-09-05
> 视觉方案：A「月视图 + 下方事件舱」

## 1. 目标

将首页首屏左侧的主标题和介绍文字替换为一个可编辑月历，让访客能够在指定日期记录多条即将发生的事件。事件只保存在当前浏览器中，不依赖账号、数据库或网络服务。

## 2. 页面位置

- 删除首页中的“探索、建造，然后发射出去。”和其下方介绍文字。
- 保留上方 `SIGNAL RECEIVED · PERSONAL STATION` 眉题。
- 保留日历下方的“查看项目”“浏览知识”按钮与状态信息。
- 右侧星际视觉装置和右下角音乐播放器保持不变。

## 3. 日历界面

日历采用“月视图 + 下方事件舱”布局：

1. 顶部显示当前年月，并提供“上个月”“今天”“下个月”三个操作。
2. 中部显示完整月历网格，以星期一作为每周第一天。
3. 今天使用青色发光描边；当前选中日期使用更明显的填充和边框。
4. 有事件的日期显示绿色光点；多条事件同时显示事件数量。
5. 下方事件舱显示选中日期、事件列表和“添加事件”入口。

整体沿用现有 C2 深空界面：深蓝黑背景、电光青强调色、细描边、轻微外发光和等宽状态文字。装饰不降低日期和事件内容的可读性。

## 4. 事件交互

- 页面首次打开时选择今天，并显示今天的事件。
- 点击任意日期后切换选中状态，同时更新下方事件舱。
- 同一天允许添加多条事件。
- 每条事件包含必填标题和可选说明。
- 添加和编辑使用日历内的紧凑表单；保存成功后立即刷新列表。
- 每条事件提供“编辑”和“删除”操作。
- 删除前显示二次确认，避免误操作。
- 标题去除首尾空白后不能为空；无效提交在表单内提示，不关闭表单。

## 5. 数据结构与存储

浏览器存储键固定为：

```text
wanderer.calendar.events.v1
```

单条事件结构：

```json
{
  "id": "唯一标识",
  "date": "2026-09-05",
  "title": "发布个人网站",
  "note": "完成部署检查",
  "createdAt": "2026-09-05T12:00:00.000Z"
}
```

事件集合序列化为 JSON 数组并写入 `localStorage`。添加、修改或删除后立即保存；刷新页面时重新读取。

## 6. 错误处理

- `localStorage` 中没有数据时使用空事件列表。
- 数据不是有效 JSON 或不符合事件数组结构时忽略损坏数据，日历仍正常显示。
- 浏览器拒绝本地存储时，当前页面内仍可使用事件功能，并显示“本次修改可能无法保留”的提示。
- 单条异常数据不影响其他有效事件显示。

## 7. 响应式与可访问性

- 桌面端日历占据原首页左栏，事件舱位于月历下方。
- 移动端保持七列日期网格，缩小间距和状态文字；事件舱自然排列在网格下方。
- 日期使用可聚焦按钮，支持键盘选择。
- 月份切换、添加、编辑和删除按钮提供明确的无障碍名称。
- 表单字段具有可见标签，错误提示与字段关联。
- 动效遵循现有 `prefers-reduced-motion` 规则。

## 8. 组件与数据流

实现保持在现有原生 HTML、CSS 和 JavaScript 架构中：

- HTML 提供日历容器、月份导航、日期网格、事件舱和事件表单。
- JavaScript 负责生成月份网格、维护选中日期、执行事件增删改和持久化。
- CSS 负责深空视觉、状态区分、响应式布局和交互反馈。

数据流为：读取本地事件 → 渲染当前月份 → 选择日期 → 渲染该日事件 → 增删改 → 保存本地事件 → 重新渲染。

## 9. 测试与验收

自动测试覆盖：

- 首页旧主标题和介绍文字已删除。
- 首页包含日历、月份导航、日期网格、事件表单和本地存储挂钩。
- 月份切换和“今天”操作正确更新视图。
- 同一天可添加、编辑和删除多条事件。
- 刷新后可从本地存储恢复事件。
- 损坏数据和存储失败不会阻止日历显示。

浏览器验证覆盖桌面端、移动端、键盘操作、刷新恢复和控制台错误。

## 10. MVP 边界

不包含：账号、云同步、服务器数据库、通知提醒、事件时间、重复事件、拖拽和第三方日历导入。
