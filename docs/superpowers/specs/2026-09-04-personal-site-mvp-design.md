# 个人网站 MVP 设计文档

> 状态：已确认视觉方向（C2「深空界面」）
> 日期：2026-09-04

## 1. 定位与目标

面向朋友、熟人和普通访客的个人空间，用于展示个人项目、简短介绍、知识分享和各平台入口。

核心目标：访客在 30 秒内了解“我是谁、做过什么、分享什么、如何找到我”。

## 2. MVP 页面

| 页面 | 核心内容 | 作用 |
| --- | --- | --- |
| 首页 `/` | 个人标识、文字介绍、精选项目、最新知识、平台链接 | 快速建立印象 |
| 项目 `/projects.html` | 项目卡片、项目状态、技术标签、项目链接 | 展示正在做和做过的事情 |
| 知识 `/notes.html` | 文章/笔记列表、摘要、分类、日期 | 持续沉淀和分享 |

不单独制作复杂的个人介绍页；首页用 2～3 句文字完成介绍，不强制使用头像。

## 3. 首页内容与示例文案

- 标识：`/// WANDERER.OS`
- 眉题：`SIGNAL RECEIVED · PERSONAL STATION`
- 主标题：**探索、建造，然后发射出去。**
- 简介：`这里记录我正在做的项目、学到的知识，以及值得分享的想法。`
- 主按钮：`查看项目`、`浏览知识`
- 项目区：展示 2～3 个精选项目
- 知识区：展示 3 篇最新文章或笔记
- 联系区：GitHub、Bilibili 及后续补充的平台链接

## 4. 视觉方向：C2「深空界面」

- **色彩**：深蓝黑为底，电光青为主强调色，紫色作为辅助色。
- **背景**：星点、深空渐变、细网格和轨道线，营造探索感。
- **组件**：半透明玻璃卡片、细描边、柔和外发光、圆角信息面板。
- **字体**：正文使用清晰的系统无衬线字体；状态、标签和导航可使用等宽字体。
- **动效**：仅使用轻微的星点闪烁、光晕和悬停反馈；支持 `prefers-reduced-motion`。
- **原则**：科幻元素服务于内容，不影响阅读、对比度和移动端操作。

## 5. 内容结构

- 项目：名称、简介、当前状态、技术标签、截图/预览、源码或演示链接。
- 知识：标题、摘要、分类、日期、正文链接；初期可直接维护静态 HTML。
- 平台链接：平台名称、账号名、外链地址；无后台表单和站内消息系统。

## 6. 技术与边界

- 采用静态 HTML + CSS，必要时使用少量原生 JavaScript。
- 初期不引入数据库、登录、后台 CMS、评论、搜索、订阅和复杂分析系统。
- 页面必须响应式，兼容桌面与移动端；使用语义化 HTML、键盘可操作焦点和基础 SEO 元信息。
- 后续可在内容稳定后接入 Markdown/静态站点生成器，不改变当前页面结构。

## 7. MVP 验收标准

1. 首页能清晰呈现个人定位、项目、知识内容和平台链接。
2. 项目页与知识页可独立访问，所有已配置链接有效。
3. 桌面端与移动端布局稳定，文字和卡片保持良好可读性。
4. 交互具备悬停、焦点和移动端反馈；系统的减少动效设置生效。
5. 页面无明显 404、控制台错误或遮挡内容的问题，可部署到现有服务器和域名。
