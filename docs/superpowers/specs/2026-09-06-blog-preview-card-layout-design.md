# 首页博客分类卡片与封面占位清理设计

## 目标

调整首页“我的博客”预览区，让三类博客以三张等宽横向卡片呈现；每张分类卡片只展示该分类最新的一篇已发布文章。分类卡片与文章子卡片承担不同导航职责，同时移除所有无意义的封面、图片占位文字和占位图。

## 已确认的交互

- 首页预览区固定展示三个分类：我的项目、心得分享、日常学习。
- 桌面端三张卡片等宽横向排列；平板端允许两列，窄屏端降为单列，保证可读性。
- 分类卡片外部区域进入对应模块主页：`notes.html?module=<module>`。
- 卡片内部的“最新文章”子卡片进入具体文章：`post.html?slug=<slug>`。
- 点击子卡片时不得触发外层分类跳转；两个入口使用独立链接和点击事件分流，并保留现有跨页过渡动画。
- 每个分类只从已发布索引中按 `updatedAt`（缺失时回退 `createdAt`）选取最新文章。
- 分类没有已发布文章时，卡片保留分类说明并显示简洁的空状态，不生成虚构文章入口。

## 视觉方向：B · 分层信号舱

- 采用现有科幻液态玻璃系统：透明深色背景、细边框、轻微星云纹理和青色交互状态。
- 分类卡片高度和宽度一致，卡片标题、说明和文章数量保持稳定的垂直层级。
- 最新文章作为卡片底部的独立内嵌面板，使用更深的背景和上边界突出“可阅读入口”。
- 子卡片展示文章标题、摘要、相对时间和阅读时长；标题过长时截断，避免破坏三栏等高布局。
- 外层分类入口提供明确的 `VIEW MODULE` / 箭头提示；子卡片提供文章阅读语义和独立 hover/focus 状态。

## 占位清理

- 删除 `COVER / SIGNAL LOST`、`IMAGE / SIGNAL LOST` 等文字占位。
- 没有封面时不创建封面占位图片或文字，只保留卡片/文章容器本身的背景材质；文章详情页没有封面时隐藏封面区域。
- Markdown 正文图片加载失败时移除该图片块及其说明，不替换为文字或占位图。
- 有真实封面时继续加载真实图片；图片加载失败也不展示占位内容。

## 实现边界

- `blog.js` 负责根据模块数据选择最新文章、渲染首页分类卡片和子卡片，并保留现有文章列表/详情渲染。
- `notes.html` 提供稳定的三个模块容器和错误/空状态钩子，不把文章数据硬编码到 HTML。
- `styles.css` 负责三栏等高布局、B 方案子卡片层级、响应式断点和无障碍焦点状态。
- 继续使用现有 `moduleHref`、`filterPostsByModule`、`sortPosts` 和页面跳转机制，不引入新依赖。

## 错误与可访问性

- 博客索引加载失败时保留现有错误提示，不渲染错误文章。
- 分类卡片使用语义化 `article` 容器；分类入口和文章入口都是可聚焦的真实链接。
- 外层卡片支持键盘 Enter/Space 触发分类链接；焦点位于子卡片链接时只执行文章跳转。
- 装饰性的背景和箭头使用 `aria-hidden`，真实文章标题作为子链接的可访问名称。
- 尊重 `prefers-reduced-motion`，不新增必须依赖动画的交互。

## 测试策略

- 单元测试验证每个模块只选出一篇最新文章，并按 `updatedAt` 优先于 `createdAt`。
- DOM 渲染测试验证三张分类卡片的模块链接、最新文章链接、标题/摘要/时间，以及无文章时的空状态。
- 测试验证外层分类入口与内部文章入口不会产生嵌套链接或错误 href。
- 内容测试验证源码中不再出现封面/图片占位文字和占位元素。
- CSS smoke test 验证桌面三栏等宽、B 方案子卡片层级、响应式布局、焦点和 reduced-motion 规则。
- 运行完整 `npm test`、Node 语法检查和 `git diff --check` 后再提交。

## 非目标

- 不改变 admin 编辑器、文章发布接口、文章 Markdown 格式或图片上传流程。
- 不改变博客分类名称、模块主页的文章列表和文章详情页的数据来源。
- 不删除真实存在的文章封面文件，只改变缺少或加载失败时的展示方式。
