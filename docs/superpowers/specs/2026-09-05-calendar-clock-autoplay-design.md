# 北京时间、自动播放与校历近期事项设计

日期：2026-09-05  
状态：方案已确认

## 1. 目标

在现有科幻个人主页中补充北京时间状态、播放器自动播放和校历近期事项，同时去除鼠标移动时的跟随光晕。现有个人事件仍只保存在当前浏览器，校历数据作为不可编辑的内置信息展示。

## 2. 已确认范围

- 所有页面右上角显示北京时间日期与当前时间，时间精确到秒。
- 页面加载时默认选择《夜の向日葵》并尝试自动播放；如果浏览器禁止带声音自动播放，首次点击页面或按 Enter/空格键时自动重试并启用声音。
- 去除鼠标跟随卡片的径向光晕和悬停外发光，保留液态玻璃的轻微倾斜、按压和边框反馈。
- 首页日历自动载入校历中的以下安排：

  | 日期 | 事项 |
  | --- | --- |
  | 2026-09-25 至 2026-09-27 | 中秋节放假 |
  | 2026-10-01 至 2026-10-07 | 国庆节放假 |
  | 2027-01-11 起 | 学生寒假 |
  | 2027-02-21 | 学生注册 |

- 不加入校历中的“教师放寒假”和“教师上班”事项。
- 不展示校历中的调休上班事项；日历按连续日期逐日标记，日期底色使用低对比度事件色，并在右下角按事件数量显示小圆点；日历旁的近期事项将连续假期合并为一项，并按开始日期取最近三项。
- 用户自定义事件与校历事件合并参与近期排序，但内置校历事件不可编辑、不可删除。

## 3. 参考与数据边界

参考 `DrTonks/tonks-home` 的 `UpcomingHolidays` 组件，其信息架构是收集未来事项、按日期排序并截取前三项；本项目采用相同的信息结构，但使用本地校历数据和浏览器本地用户事件，不引入后端请求。[参考实现](https://github.com/DrTonks/tonks-home/blob/main/src/components/calendar/UpcomingHolidays.vue)

本次以用户提供的北京师范大学 2026—2027 学年第一学期校历图片为日期来源。图片中未确定的 2027 年元旦、春节安排不自行推测，后续可在数据表中补充正式通知。

## 4. 实现方案

### 北京时间模块

新增 `clock.js`，使用 `Intl.DateTimeFormat` 的 `Asia/Shanghai` 时区生成日期、星期和 `HH:mm:ss`，每秒更新共享页头中的 `<time>` 节点。纯格式化函数导出给 Node 测试，页面初始化函数负责定时器和 `datetime` 属性。

### 播放器

在音频元素声明 `autoplay`，初始化默认曲目时传入自动播放参数。播放被浏览器策略拦截时区分“自动播放被拦截”和“音频文件加载失败”，并监听首次页面点击或键盘确认操作，在用户手势中自动重试播放；现有播放按钮仍可直接控制音乐。

### 卡片交互

保留 `liquid-glass.js` 的指针定位和倾斜计算，隐藏跟随鼠标的 `.liquid-glass__shine`，移除激活态的外发光阴影。触碰反馈仍通过缩放和边框变化表达。

### 校历与近期事项

在 `calendar.js` 中增加不可变的校历数据、日期范围展开、指定日期查询和近期事项合并函数。渲染月历时将校历标记和用户事件数量写入日期单元格；每个事件渲染一个右下角小圆点，事件日期只使用低对比度底色；选中日期时同时展示校历信息和用户事件。新增的近期事项面板只读显示名称、日期范围和“今天/明天/N 天后/进行中”等相对时间。

## 5. 响应式与可访问性

- 页头状态在桌面端位于导航右侧，移动端压缩为两行并保持不遮挡菜单按钮。
- 校历事项使用颜色标签和文本，不依赖颜色单独传达含义；内置事项不会出现编辑/删除按钮。
- 时钟使用 `<time>` 元素；每秒变化的时间不使用会持续打断读屏的 `aria-live`。
- 近期事项为空时显示明确的空状态。
- `prefers-reduced-motion` 下不新增持续动画；播放器、时钟和日历功能保持可用。

## 6. 测试与验收

- 单元测试覆盖北京时间格式化、校历范围展开、连续假期合并、最近三项排序、教师事项和调休事项排除。
- 页面烟测覆盖三页页头时钟钩子、自动播放与用户手势恢复钩子、无鼠标光晕样式、首页近期事项结构和校历日期圆点。
- 浏览器验证桌面端、移动端和减少动效模式，确认时钟每秒更新、播放器自动播放或在首次用户操作后恢复、卡片不出现跟随光晕、日历和近期事项显示正确。
