# 全站液态玻璃卡片设计

> 状态：已确认  
> 日期：2026-09-05  
> 方案：B「指针驱动的液态玻璃」

## 1. 目标

为网站主要卡片加入与 C2 深空风格一致的液态玻璃材质和即时动效反馈。效果应增强层次与触感，不干扰阅读、链接点击、日历编辑或音乐播放。

## 2. 应用范围

统一覆盖：

- 项目卡片、知识卡片和联系方式卡片；
- 首页日历与空间站面板；
- 右下角音乐播放器。

日期按钮、普通导航按钮、表单输入框等小型控件不独立套用液态玻璃，以免视觉过密。

## 3. 材质表现

卡片保留原有深蓝透明底色，并叠加三层视觉：

1. 半透明模糊背景与轻微饱和度提升，形成玻璃主体；
2. 随指针移动的径向高光，模拟光线在曲面玻璃中的折射；
3. 青色与紫色的细边缘高光，在悬停时增强但不覆盖正文。

高光位置通过 CSS 自定义属性传递，不创建 Canvas 或 WebGL，保证静态网站的加载速度与维护成本。

## 4. 动效反馈

- 桌面指针进入卡片后，卡片最多倾斜约 `2deg`，向上浮起不超过 `4px`，高光连续跟随指针。
- 指针离开后从当前状态平滑复位，不锁定交互。
- 鼠标或触摸按下时立即缩放至约 `0.99`，松开或取消后回弹。
- 触摸设备不启用持续倾斜，只保留按压与短暂高光反馈，避免页面滚动时晃动。
- 动效时长控制在约 `180–360ms`，默认采用接近临界阻尼的收束感，不使用持续弹跳。

## 5. 实现结构

- CSS 定义共享的 `.liquid-glass` 材质、伪元素高光和交互状态。
- HTML 为范围内卡片增加统一标记，不改变原有语义和链接结构。
- 独立 JavaScript 模块监听 Pointer Events，使用 `requestAnimationFrame` 更新指针位置与倾斜变量。
- 脚本只增强视觉；脚本加载失败时，卡片仍保留静态玻璃材质和全部原有功能。

## 6. 可访问性与性能

- `prefers-reduced-motion: reduce` 下禁用倾斜、浮起和缩放，仅保留静态材质与颜色反馈。
- 键盘聚焦使用现有清晰描边，不依赖悬停才能辨认交互状态。
- 高光层设置 `pointer-events: none`，不会遮挡按钮、表单或链接。
- 每个指针帧最多安排一次样式更新；离开视口或隐藏页面时不持续运行动画。
- 移动端不监听高频指针移动，降低耗电和滚动干扰。

## 7. 测试与验收

自动测试覆盖：

- 所有目标卡片具有统一液态玻璃标记；
- 指针位置、倾斜和按压状态可正确更新与复位；
- 减少动态模式存在明确的禁用规则；
- 高光层不接收指针事件；
- 现有日历、链接和音乐播放器测试继续通过。

浏览器验收覆盖桌面悬停、按压、离开复位、移动端无横向溢出、减少动态模式以及控制台错误。

## 8. 边界

本次不加入拖拽、卡片惯性移动、WebGL 实时折射、声音反馈或设备陀螺仪控制。
